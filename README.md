# Sonar-Signal-Classification-using-Machine-Learning-SVM- 

## 📌 Project Overview
This project focuses on Sonar Signal Classification using Machine Learning techniques.  
The objective is to classify sonar signals as either:

- Rock (R)
- Mine (M)

The model is trained using the Support Vector Machine (SVM) algorithm to achieve high classification accuracy.

## 📊 Model Used

### Support Vector Machine (SVM)

SVM is a supervised machine learning algorithm used for classification tasks.  
It works by finding the optimal hyperplane that separates the classes effectively.
